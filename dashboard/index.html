$δ$-mem: Efficient Online Memory for Large Language Models

$δ$-mem은 LLM이 장기 정보를 효율적으로 기억하고 재사용하도록 돕는 경량 메모리 메커니즘입니다. 이는 frozen full-attention backbone에 compact online state of associative memory를 통합하고 delta-rule learning으로 과거 정보를 고정 크기 상태 행렬로 압축하여 attention 계산에 low-rank corrections를 생성함으로써, context 확장이나 full fine-tuning 없이도 메모리 의존적인 작업에서 상당한 성능 향상을 달성합니다.
